Rapidplay

Privacy Policy

Effective and last updated: October 6, 2026

Rapidplay controls standard HTML5 video and audio playback speed. The extension operates locally, without an account, analytics, a developer backend, or remote executable code.

Data handled on your device

  • Local preferences: shortcut combinations, presets, step size, panel hue and opacity, and whether Rapidplay is paused, stored in chrome.storage.local.
  • Session state: playback rates, scopes, tab IDs, tab activity timestamps, reload flags, and page hostnames, stored in chrome.storage.session. Hostnames are remembered for tabs using the controller, including when a site override has not been selected, to resolve the This Site scope. Full page URLs, page text, media contents, and browsing history are not saved.
  • Page and media access: while enabled, packaged content scripts inspect the DOM for video/audio elements and maintain their playback rate and pitch preservation. The controller loads after media detection or a toolbar click. Keyboard events are handled for shortcuts and recording user-selected combinations; keystrokes are not logged or transmitted.

Paused mode

Pausing returns currently tracked media to 1× and stops media discovery and playback control. The small detector remains loaded to receive extension messages and read the locally stored pause choice. The toolbar may load the panel while paused; panel display, layout, focus, and fullscreen handling still access the page DOM. Pausing does not revoke Chrome’s website-access permission.

Permissions and purpose

The only API permission is storage, for local preferences and session state. Static content scripts match http://*/* and https://*/*, including frames, so playback can be controlled on sites not known in advance. This creates broad website access even without a separate host_permissions field. Chrome may warn that the extension can read and change website data. Spotify and its subdomains are excluded. Chrome internal pages and the Chrome Web Store do not allow these scripts.

Sharing and network use

The extension does not send settings, hostnames, keystrokes, page contents, or media to the developer or third parties. It makes no outbound network requests; its controller reads a packaged CSS file from its own extension URL. It does not sell data or use it for advertising. Websites and Chrome have their own separate data practices.

Retention and controls

Local preferences remain until changed, extension data is cleared, or Rapidplay is uninstalled. Session data is cleared by Chrome when the browser session ends or the extension is reloaded, disabled, or updated. Tab data is removed when tabs close; tab overrides are cleared on normal page reloads and pruned after approximately 30 minutes without tab use when state is next handled. Restoring a discarded tab preserves its override. Site overrides remain for the session.

Use the power button to pause playback control, Chrome’s site-access settings to limit allowed sites, or chrome://extensions to disable or remove Rapidplay. Uninstalling removes its Chrome extension storage.

Limited Use

Use of information received from Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only for the disclosed playback-control purpose.

This website

This documentation site uses static HTML and local images, with no analytics, third-party scripts, or cookies set by the site. GitHub Pages serves it and may process ordinary request information under GitHub’s privacy policy. Visiting this site is separate from using the extension.

Changes and contact

Material changes to data handling will be disclosed and this policy updated. For privacy questions or support, open a repository issue or use the publisher contact shown on the Chrome Web Store listing when available. Avoid including private browsing information in public issues.
